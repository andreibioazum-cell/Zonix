# Рекомендуемый дистрибутив для Zonix (KDE Plasma)

## Лучший выбор: KDE Neon

**KDE Neon** — самый оптимизированный дистрибутив для работы с KDE Plasma.

### Почему KDE Neon:

- **Разработан командой KDE** — здесь всегда самая последняя версия Plasma, как только она выходит
- **Оптимизирован под Plasma** — все пакеты собраны специально для KDE, ничего лишнего
- **База Ubuntu LTS** — стабильность и поддержка на годы
- **Лёгкий и быстрый** — нет лишних программ, которые тормозят систему
- **Бесплатно** — с открытым исходным кодом

### Скачать:

https://neon.kde.org/download

### Альтернативы (если KDE Neon не подходит):

| Дистрибутив | Плюсы | Минусы |
|-------------|-------|--------|
| **Kubuntu** | Стабильный, простой в установке | Старее версии Plasma |
| **Fedora KDE** | Современные пакеты | Чаще обновления, может быть меньше стабильности |
| **openSUSE KDE** | Мощные инструменты администрирования | Сложнее для новичков |

### Как установить:

1. Скачайте ISO с сайта KDE Neon
2. Запишите на флешку (Rufus, BalenaEtcher)
3. Загрузитесь с флешки и установите

Для запуска в v86 / VirtualBox используйте скачанный ISO напрямую — он уже содержит полноценную графическую оболочку KDE Plasma с рабочим столом, как в Windows.
